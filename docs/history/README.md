# Historical plans and reviews

Design plans and pre-release reviews from 0.8 through 0.17, kept because the
reasoning in them is still referenced from the code — several source comments
point here for *why* a structure is shaped the way it is.

They are **not** documentation. They describe what was intended at the time,
which in places is not what shipped. For how Portside behaves now, see the
docs one directory up.
